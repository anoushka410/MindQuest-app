# MindQuest

MindQuest is a playful general-knowledge learning app inspired by short daily lesson loops.

It includes learning paths for history, politics, geography, psychology, philosophy, religion, science, and space, plus a mixed daily quiz and review queue for missed questions.

## Run locally

Open `index.html` in a browser.

## Publish

This app is static, so it can be hosted on GitHub Pages, Netlify, Vercel, Cloudflare Pages, or any static file host.
